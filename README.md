# TRADING SPACE

Aplicación React con Vite para la demostración del sistema TRADING SPACE.

## Showroom 3D

El panel incluye una sección independiente **Showroom 3D**, construida con
Three.js, React Three Fiber y Drei. Para abrirla, inicia sesión y selecciona
**Showroom 3D** en el menú lateral.

- Arrastra la escena para girar la cámara.
- Usa la rueda del ratón o el gesto de zoom para acercarte y alejarte.
- Pulsa **Restablecer vista** para volver al encuadre inicial.

## Desarrollo

```sh
npm install
npm run dev
```

Validación local:

```sh
npm run build
npm run lint
```
